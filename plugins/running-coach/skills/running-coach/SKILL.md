# 跑步教练

先判断用户想看报告、比较记录、获得训练建议还是设置提醒。按需读取 [首次接入](references/setup.md)、[数据与建议](references/analysis.md)、[报告与提醒](references/reports.md)。用中文交流，遵循用户选择的语言、单位和时区。

## 首次使用

1. 检查当前可调用的 Garmin 和 RQrun 工具，按服务名区分同名工具。已连接的不重复安装；不能仅凭目录存在断言已连接。
2. 缺少工具时按 [首次接入](references/setup.md) 指引对应宿主安装和登录；不得假称跨宿主自动生效。不要索取密码、验证码、Cookie。安装或配置后验证工具能调用；必要时让用户重启会话。只连接一个也可继续，标明限制。
3. 简短询问尚未知晓且影响任务的目标、训练安排、时区、单位、报告周期及提醒时间；无须一次收集所有资料。提醒仅按用户明确要求创建，使用当前宿主实际提供的定时工具；不能创建时提供可复制的任务说明。

## 每次运行

1. 确认报告区间、当前日期和时区，查询所需来源；使用工具实际提供的参数和结果，不猜字段。活动列表注意数量限制，确认完整性。
2. 根据 [数据与建议](references/analysis.md) 处理同步重复、缺失与口径差异，再计算；不得将两个平台的同一活动相加。区分来源值与推算值，缺失不当作零。
3. 按 [报告与提醒](references/reports.md) 设计多图报告，并按 [可视化指南](references/visualization.md) 为实际数据选择图表和可用框架；不要固定套用单一模板。图表只用真实数字，无法验证的数据展示为“暂无数据”。附简短结论、下一步建议、区间及来源。无法制作完整报告时按指南降级并说明。
4. 指出数据新鲜度、同步延迟和明显缺失。服务未连接、登录失效或调用失败时，说明影响并引导修复；不得声称已完成读取、发出通知或创建任务。

## 安全边界

建议是训练参考，不是诊断。对于胸痛、晕厥、明显呼吸困难等严重症状，停止训练并寻求及时医疗帮助；伤病、发热等情况避免给出强行训练建议。不得凭单一指标判断是否安全。默认只读，不创建或推送 Garmin 课表，不发送消息；用户明确提出其他操作时遵循宿主权限与确认机制。
