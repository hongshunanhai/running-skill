# 数据与训练分析

- 常用工具：两端 `list_activities`、`get_period_stats`、`get_training_status`；Garmin `get_health`、`get_training`；RQrun `get_intensity`、`get_runlevel`。单次细节用对应 `get_activity`，调用前先取得该平台自己的 ID。两端 `render_chart` 可生成训练和周跑量图。
- 根据时间、运动类型、时长和距离综合匹配活动。明确一对一、强一致的记录才作为同一次；多候选或信息不足保留待确认，不默默合并。优先使用用户选择的主数据源，默认以 Garmin 活动列表作为总量口径，RQrun 用于对照；主源缺失时注明备用来源。不能确定匹配或完整性时不输出合并后的精确总量。
- 不跨源混加各自的汇总；报告列出来源、时区、范围、计量单位、未匹配数量。比较同一次活动的距离、时长、配速时分别标示来源及差异；暂停时间、距离算法、时区和同步延迟可能造成差异，不假设哪方错误。平均配速用总运动时间除以总距离，数据口径不一致时不计算。
- 训练建议同时考虑用户目标、既定训练安排、最近负荷与趋势、睡眠、恢复状态和用户自述；数据不足时说明不确定性，给温和选项。HRV、恢复时间和负荷是平台估算，解释其时间与来源，不按未经验证的阈值做诊断。
- 长期比较需可比区间、足够历史记录；分母为零时不算百分比。不要生成未记录的指标、预言成绩或伪造因果关系。明示用户可调整或暂停建议。
